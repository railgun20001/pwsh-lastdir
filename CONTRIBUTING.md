# Contributing / 参与贡献

欢迎通过 GitHub Issue 报告可复现的问题，或提交 Pull Request。请说明 PowerShell 版本、启动方式、预期行为和实际行为。提交前请分别在 PowerShell 7.6.6 和 Windows PowerShell 5.1 中运行 `./tests/test.ps1`。

Issues and pull requests are welcome. Include your PowerShell version, how the shell was started, and the expected and actual behavior. Before submitting a pull request, run `./tests/test.ps1` with both PowerShell 7.6.6 and Windows PowerShell 5.1.

请保持安装与卸载行为可重复执行，并避免覆盖用户 profile 中无关的配置。 / Keep installation and uninstallation repeatable, and preserve unrelated user profile configuration.
