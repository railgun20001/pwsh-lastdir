# Security Policy / 安全政策

此工具会修改当前用户的 PowerShell profile，并在提示符出现时写入当前目录。请仅从可信来源安装。发现安全问题时，请使用 GitHub 仓库的 **Private vulnerability reporting** 功能；如果该功能不可用，请联系仓库维护者，避免在公开 Issue 中披露利用细节。

This tool changes the current user's PowerShell profile and writes the current directory when the prompt appears. Install it only from a trusted source. For security issues, use the repository's **Private vulnerability reporting** feature when available; otherwise contact the maintainer instead of posting exploit details in a public issue.
